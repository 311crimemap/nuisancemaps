You are given a JSON list of metadata "resource" objects.

Label as 'true' whether each "resource" object describes a crime incident report
dataset, or a 311 dataset with location data (latitude, longitude, geolocation
point) from the year 2020 onward.

Label as 'false' any resource that is NOT crime, police or 311 related.

Label as 'false' any type of map or visualization.

Label as 'false' any data from the Fire department.

Label as 'false' any crime datasets that consist of active calls, dispatch, or
arrests.

Return a JSON array labeled "results". Each element is an object with a boolean
field "label" containing the evaluated label ('true' or 'false'), a field
"resource_id" that contains the resource's id, and a field "type" with values
"crime", "311", or None, respectively.

Ensure each input object returns a value.
